# Rule based AI Chatbot

This is a simple rule-based AI chatbot web project built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page structure
- `style.css` — styling for the chat interface and page layout
- `script.js` — chatbot logic and behavior

## Usage

1. Open `index.html` in a web browser.
2. Type a message into the chat input.
3. The chatbot responds based on predefined rules in `script.js`.

## Notes

- This project does not use machine learning; it responds using hard-coded rules.
- You can extend the chatbot by adding new patterns and responses in `script.js`.
